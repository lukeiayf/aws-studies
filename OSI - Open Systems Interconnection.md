The OSI (Open Systems Interconnection) model splits networking functions into seven layers. 

- At the bottom, Layer 1 is the Physical layer, devoted to transmitting raw bits over a physical medium (such as cables or radio waves). 

- Above that, Layer 2 is the Data Link layer, handling node-to-node data transfer and basic error checking. 

- Layer 3 is the Network layer, which focuses on routing, forwarding, and logical addressing (for example, assigning IP addresses). 

- Layer 4 is the Transport layer that handles end-to-end delivery through protocols such as [[TCP - Transmission Control Protocol]] (connection-oriented) or [[UDP - User Datagram Protocol]] (connectionless).

- Layer 5 is the Session layer, which manages and synchronizes the dialogues (or sessions) between applications. 

- Layer 6 is the Presentation layer, which translates, encrypts, or compresses data so that it can be understood at either end. 

- Finally, Layer 7 is the Application layer, where applications like web browsers or email clients interact with the underlying network.
