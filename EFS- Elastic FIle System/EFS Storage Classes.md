- **EFS Standard** for frequently accessed data,  
- [[EFS-IA - EFS Infrequent Access]] Standard-IA for infrequently accessed data,  
- **EFS One Zone** for lower-cost storage in a single Availability Zone,  
- **EFS One Zone-IA** for the lowest-cost, infrequently accessed, single-AZ storage.

You can set lifecycle management to move files between these classes.
