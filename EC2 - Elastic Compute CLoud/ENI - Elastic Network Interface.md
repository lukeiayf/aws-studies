Elastic Network Interfaces (ENIs) are virtual network interfaces that you can attach to [[EC2]]instances in Amazon Web Services (AWS). Think of them as **virtual network cards**. They enable instances to connect to your [[VPC Endpoints]] 

- ENIs have a lifecycle independent of the EC2 instance they are attached to. You can create, attach, detach, and move them between instances.

**THEY ARE USEFUL FOR QUICK FAILOVER AS YOU CAN DETACH AND ATTACH THEM TO DIFFERENT INSTANCES**
